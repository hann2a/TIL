# 변수와 타입 
from 자바의 정석

## 변수의 선언
- 변수 이름은 메모리 주소에 붙여진 이름 
- 프로그램은 **변수 이름을 통해서 메모리 주소에 접근**하고, 그곳에 값을 저장하거나 그곳에 있는 값을 읽는다. 

## 변수의 사용 
- 리터럴: 소스 코드 내에서 직접 입력된 값
- 정수 리터럴, 실수 리터럴, 문자 리터럴, 논리 리터럴 

### 정수 리터럴
- 소수점이 없는 정수 리터럴은 10진수로 간주 
- 0으로 시작되는 리터럴은 8진수로 간주 
- 0x 또는 0X로 시작하고 0~9 숫자나 A, B, C, D, E, F 또는 a, b, c, d, e, f로 구성된 리터럴은 16진수로 간주
- 정수 리터럴을 저장할 수 있는 타입은 byte, char, short, int, long 

### 실수 리터럴 
- 소수점이 있는 리터럴은 10진수 실수로 간주 
- 대문자 E 또는 소문자 e가 있는 리터럴은 10진수 지수와 가수로 간주 
    - 가수는 기준이 되는 값 
    - 지수는 10을 몇번 곱하거나 나누는지
    - 가수와 10의 몇 승인지가 곱하기로 이어져 있음
- 실수 리터럴을 저장할 수 있는 타입은 float, double

### 문자 리터럴 
- 작은 따옴표로 묶은 텍스트는 하나의 문자 리터럴로 간주 

### 문자열 리터럴 
- 큰따옴표로 묶은 텍스트. 텍스트가 없어도 문자열 리터럴로 간주. 
- String 타입만 존재 

### 논리 리터럴 
- true와 false는 논리 리터럴로 간주 
- boolean 타입 

## 변수값 읽기 
- 초기화되지 않은 변수는 읽을 수가 없다. 
- 초기화란 값을 처음 부여 받는 것. 

## 변수의 사용 범위 
- 변수는 중괄호 블록 내에서 선언되고 사용된다. 
- 일단 모든 변수는 메소드 블록 내에 존재한다고 생각하자. 
- 메소드 블록 내에서 선언된 변수를 로컬 변수라고 부름. 
- 로컬 변수는 메소드 실행이 끝나면 메모리에서 자동으로 없어진다. 
- 변수는 선언된 블록 내에서만 사용이 가능함. 
- 메소드 블록 내에서도 여러 중괄호 블록이 있을 수 있는데 조건문 if, 반복문 for, while 등이 중괄호를 가질 수 있다. 
    - 이러한 것을 제어문이라고 한다. 
    - 제어문 블록에서 선언된 변수는 해당 제어문 블록 내에서만 사용이 가능하고 블록 밖에서는 사용할 수 없다. 

## 데이터 타입 
- 변수를 선언할 때 주어진 타입은 사용 도중에 변경할 수 없다. 

### 기본 타입 
- 정수 byte 1 byte
    - byte 타입은 1바이트짜리 데이터를 다루기 위해 존재 
    - 파일/네트워크 같은 바이너리는 바이트 단위로 오가므로 자연스럽다.
