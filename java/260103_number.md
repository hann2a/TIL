# 헷갈리는 진수 

## 16진수 
- 0x10 
- 16진수 hex
- 0x10 = 16
- 0x20 = 32
- 0x100 = 256 
- 10~15는 A~F로 표시함 
- 0x0F = 15 

## 8진수 
- 0으로 시작하면 8진수
- 010 = 8 

## 2진수 
- 0b1111 = 15

# 비트 연산 
- `&`, `|`, `<<` 같은 비트 연산은 비트 단위로 작동하기 때문에 2진수로 보면 어느 비트가 남고 꺼지는지 한 눈에 보인다. 
- 16진수 한 자리는 2진수 4자리로 정확히 대응된다 
- `0x3C` = `0011 1100`
- `0x0F` = `0000 1111`
- `0x0F`은 하위 4비트만 남기라는 뜻으로 많이 나옴. 
- `|`은 둘 중 하나라도 1이면 1 
- 마스크에 0을 넣어두고 and를 하면 꺼진다 
- 마스크에 1을 넣어두고 or을 하면 켜진다
